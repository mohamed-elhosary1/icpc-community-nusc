# ICPC Community NUSC

> Together We Code, Together We Win.

Official web platform for the **ICPC Community NUSC** — a competitive programming community focused on learning, problem solving, teamwork, training, and competition.

---

## 🚀 Features

- **Public Hub**: Community overview, roadmap, training tracks, events, and resources.
- **Role Tracks**: Dedicated onboarding tracks for Organizing Team and Community Participants.
- **Admin Management Portal**: Real-time evaluation dashboard, interview scoring, applicant filtering, and event coordination.
- **Serverless API**: Fast, ephemeral runtime endpoints hosted on Vercel.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Space Grotesk / Outfit / Courier Prime typography, Pixel Design System
- **Backend**: Node.js Serverless Functions (`/api/*`)
- **Hosting**: Vercel

---

## 💻 Local Development

1. Clone repository:
   ```bash
   git clone https://github.com/mohamed-elhosary1/icpc-community-nusc.git
   cd icpc-community-nusc
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local development server:
   ```bash
   npm start
   # Or: node server.js
   ```

4. Visit `http://localhost:3000` (Admin portal at `/admin`).
